# Еволюційні алгоритми для оптимізації моделей машинного навчання в умовах обмежених даних (Small Data)

## Про проєкт

Репозиторій містить експериментальний код магістерського дослідження щодо застосування **еволюційних алгоритмів (EA)** для налаштування моделей машинного навчання в умовах дефіциту даних (**Small Data**).

Проєкт порівнює кастомний еволюційний алгоритм із робастною фітнес-функцією проти класичних методів оптимізації (**GridSearchCV**, **RandomizedSearchCV**, **Optuna**) на трьох моделях: **SVM**, **Random Forest (RF)** та **XGBoost (XGB)**.

## Ключові особливості

* **Відсутність витоку даних:** сувора вкладена крос-валідація (`StratifiedKFold`) із масштабуванням (`StandardScaler`) виключно всередині фолдів.
* **Робастна фітнес-функція:** замість звичайної середньої точності оптимізується стабільність моделі:
```text
  F = μ - σ · α - λ · (N_active / N_total)
```
  де `μ` – середня точність CV, `σ` – стандартне відхилення між фолдами, `α` – коефіцієнт штрафу за дисперсію, `λ` – штраф за частку активних ознак.
* **Генетичні оператори:** ко-еволюційна бінарна маска ознак, логарифмічний кросовер, елітизм та адаптивна мутація за правилом 1/5 Рехенберга.
* **MLOps-трекінг:** усі параметри та метрики логуються в **MLflow**.

## Використані датасети

Для експериментів використано 3 табличні бенчмарки з репозиторію OpenML та 1 текстовий корпус із різним ступенем дефіциту даних (`N / p`):

| Датасет | Зразків (`N`) | Ознак (`p`) | `N / p` | Галузь / Призначення | Джерело |
| :--- | :---: | :---: | :---: | :--- | :--- |
| **Sonar** | 208 | 60 | **3.47** | Гідроакустика (екстремальний Small Data, основний для абляцій) | [UCI](https://archive.ics.uci.edu/dataset/151/connectionist+bench+sonar+mines+vs+rocks) / [OpenML](https://www.openml.org/d/40) |
| **Stress Classification** | 1822 | 500 *(TF-IDF)* | **3.64** | NLP / Багатокласова класифікація типів стресу (4 класи) | [stress_data.xlsx](stress_data.xlsx) |
| **Ionosphere** | 351 | 34 | **10.32** | Фізика атмосфери (середній дефіцит, дисбаланс класів) | [UCI](https://archive.ics.uci.edu/dataset/52/ionosphere) / [OpenML](https://www.openml.org/d/59) |
| **Wine** | 178 | 13 | **13.69** | Хімічний аналіз (базовий контрольний бенчмарк) | [UCI](https://archive.ics.uci.edu/dataset/109/wine) / [OpenML](https://www.openml.org/d/187) |

> Датасети **Sonar**, **Ionosphere** та **Wine** завантажуються автоматично через `sklearn.datasets.fetch_openml`. Для **Stress Classification** виконується `TfidfVectorizer` (до 500 найважливіших ознак без англійських стоп-слів) виключно всередині навчальних фолдів для запобігання витоку даних.
